# Calendar — Delta

## MODIFIED Requirements

### Requirement: Загрузка данных календаря

Система MUST загружать производственный календарь из внешнего источника при открытии приложения. Данные считаются стабильными для сессии и не перезагружаются автоматически. Если запрос к внешнему источнику не удался после всех повторных попыток, система MUST использовать локальный fallback-генератор для соответствующего года.

#### Scenario: Успешная загрузка

- **WHEN** приложение открывается
- **THEN** календари загружены для отображаемых годов и доступны для расчётов

#### Scenario: Ошибка загрузки

- **WHEN** запрос к внешнему источнику не удаётся
- **THEN** система повторяет попытку (до 2 повторных попыток)

#### Scenario: Fallback при сетевой ошибке

- **GIVEN** запрос к isdayoff.ru не удался и все повторные попытки исчерпаны
- **WHEN** требуется календарь за соответствующий год
- **THEN** система использует локальный fallback-генератор для этого года

### Requirement: Отслеживание источника данных календаря

Система MUST отслеживать, что календарь за год сгенерирован через fallback (официальный производственный календарь РФ недоступен). Функция загрузки календаря SHALL возвращать метаданные об источнике данных: флаг `isFallback` — истинно, если использован fallback-генератор, включая случай, когда данные не были получены из-за сетевой ошибки.

#### Scenario: Календарь загружен из API isdayoff.ru

- **WHEN** загрузчик получает данные из isdayoff.ru за год 2026
- **THEN** флаг `isFallback` = false

#### Scenario: Календарь сгенерирован через fallback

- **WHEN** isdayoff.ru не вернул данные за год 2027 и использован fallback-генератор
- **THEN** флаг `isFallback` = true

#### Scenario: Сетевая ошибка

- **GIVEN** все попытки загрузки данных за 2026 год с isdayoff.ru завершились ошибкой
- **WHEN** требуется календарь за 2026 год
- **THEN** флаг `isFallback` = true, данные от fallback-генератора
