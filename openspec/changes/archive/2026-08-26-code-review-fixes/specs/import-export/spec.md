# Import / Export — Delta

## MODIFIED Requirements

### Requirement: Импорт из JSON с полной заменой

Система MUST загружать данные из JSON-файла, валидировать их схемой zod и полностью заменять текущие данные в хранилище. Каждая секция данных записывается целиком, заменяя содержимое соответствующего ключа хранилища; предварительная очистка хранилища не выполняется.

#### Scenario: Успешный импорт

- **GIVEN** пользователь выбирает файл с валидным JSON
- **WHEN** завершена загрузка файла
- **THEN** текущие данные заменены импортированными, приложение отображает новые данные

#### Scenario: Ошибка валидации при импорте

- **GIVEN** файл содержит невалидный JSON (отсутствует обязательное поле)
- **WHEN** пользователь пытается импортировать
- **THEN** показана ошибка, текущие данные сохранены без изменений

#### Scenario: Невалидный формат файла

- **GIVEN** файл не является корректным JSON
- **WHEN** пользователь пытается импортировать
- **THEN** показана ошибка парсинга, текущие данные сохранены

### Requirement: Порядок операций при импорте

Система MUST выполнять импорт полной записью: при записи секции всё содержимое соответствующего ключа хранилища заменяется (массив — целиком, настройки — целиком). Система MUST NOT очищать хранилище до валидации и записи импортированных данных. Если запись одной из секций завершилась ошибкой, незаписанные секции сохраняют предыдущие данные.

#### Scenario: Полная замена секций

- **GIVEN** текущие данные: 5 окладов, 3 премии
- **WHEN** импортированы данные: 2 оклада, 1 премия
- **THEN** после импорта: ровно 2 оклада и 1 премия, старые записи удалены

#### Scenario: Ошибка записи части секций

- **GIVEN** произошла ошибка при записи одной из секций
- **WHEN** импорт прерван
- **THEN** незаписанные секции сохраняют предыдущие данные, пользователю показана ошибка
