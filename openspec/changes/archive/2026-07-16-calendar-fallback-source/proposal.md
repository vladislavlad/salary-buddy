## Why

API isdayoff.ru не публикует данные за будущие годы заранее (например, 2027). Когда приложение пытается загрузить календарь для такого года, API возвращает строку из одних нулей — расчёты выплат пропускают этот год (`if (!calendarData) continue`), пользователь видит пустой календарь и не может планировать выплаты.

## What Changes

- Добавить локальный fallback-генератор календаря: субботы/воскресенья (код 1) + государственные праздники РФ (код 8) + 7 дней в январе (коды 1–7 = код 8).
- Внедрить интерфейс `CalendarSource` с двумя реализациями: `isdayoff.ru` и `fallback`.
- Добавить стратегию переключения: если isdayoff.ru вернул строку из одних нулей — автоматически использовать fallback.
- Сохранить обратную совместимость: потребители (`CalendarProvider`, расчёты, отпуска) не меняют API — получают тот же `Map<number, CalendarData>`.
