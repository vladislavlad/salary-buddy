## Why

Приложение настраивает и рассчитывает выплаты только за 2024–2027 годы (диапазон вычисляется из таблицы `yearSettings`). Нужно расширить поддержку до 2020–2023, чтобы пользователь мог рассчитывать авансы, зарплаты, отпускные и больничные за эти годы. Дополнительная сложность: `isdayoff.ru` для 2020–2021 возвращает ковидные (карантинные) дни, которые сейчас выглядят как обычные выходные и искажают расчёт рабочих дней.

## What Changes

- Расширить таблицу годозависимых настроек до 2020–2027: добавить строки 2020, 2021, 2022, 2023 (МРОТ, шкалы НДФЛ, отдельная база РК, макс. ежемесячная страховая выплата по травме) и расширить таблицу предельных баз страховых взносов назад до 2018 (лимиты СДЗ года N используют базы (N-1) и (N-2)).
- Диапазон поддерживаемых лет вычисляется из таблицы, поэтому минимальный год автоматически станет 2020 (отдельных констант менять не нужно).
- Календарь: при запросе `isdayoff.ru` передавать параметр `covid=1`, чтобы ковидные дни возвращались отдельным кодом 4 (сейчас они смешиваются с обычными выходными, код 1).
- Новая внутренняя настройка приложения «учитывать ковидные дни» (persisted, по умолчанию «нет»; без UI — настройка не пользовательская).
- В этом изменении реализуется только режим «без ковидных дней»: ковидные дни (код 4) считаются рабочими и на календаре не отрисовываются. Режим «с ковидными днями» — будущая доработка.
- Настройки по годам (year-settings): добавить список праздничных дней года (официальные праздники, код 8; ст. 112 ТК РФ: 1–6 января и 8 января, 23.02, 08.03, 01.05, 09.05, 12.06, 04.11). При загрузке календаря этот список накладывается поверх данных любого провайдера (установка кода 8) — чинит годы 2020–2021, где API возвращает праздники как код 1 (иначе ломается продление отпуска на праздники).
- Fallback-генератор: список новогодних праздников привести к ст. 112 ТК РФ (сейчас 1–7 января; правильно — 1–6 января и 8 января).
- На будущее (не в этом изменении): внутригодовое изменение значений (напр. МРОТ 2022) — хранить как массив `[{датаНачала, сумма}, ...]`.

### Modified Capabilities

- `year-settings`: таблица настроек покрывает 2020–2027; таблица предельных баз взносов расширяется до 2018; диапазон поддерживаемых лет становится 2020–2027; добавляется список праздничных дней года (код 8).
- `calendar`: обработка ковидных дней (код 4) через параметр `covid=1`; новая внутренняя настройка приложения «учитывать ковидные дни» (без UI); режим «без ковидных дней» (код 4 → рабочий день, не отрисовывается); наложение праздничных дней (код 8) поверх календаря из любого провайдера; список праздников в fallback приводится к ст. 112 ТК РФ (1–6 января и 8 января).
- `ndfl`: шкала НДФЛ по годам дополнена 2020 (плоская 13%) и расширена до 2021–2024 (13% до 5 млн, 15% свыше).
- `sick-leave`: таблица лимита пособия по производственной травме расширяется до 2020–2023.

## Impact

- `src/shared/lib/yearSettings.ts` — строки 2020–2023, предельные базы 2018–2021, список праздничных дней года.
- `src/features/calendar/model/isdayoff-fetch.ts` — параметр `covid=1`, распознавание кода 4.
- `src/features/calendar/model/calendar.ts` — маппинг кода 4 в рабочий день (режим «без ковидных дней»); наложение праздничных дней (код 8) поверх календаря.
- `src/features/calendar/model/calendar-fallback.ts` — список праздников января (1–6 и 8).
- `src/features/calendar/model/CalendarProvider.tsx` — чтение настройки и передача в загрузку календаря.
- Новый слой `repository` в фиче `calendar` (persisted настройка приложения) + тип в `src/shared/types`.
- Тесты: `yearSettings` (новые годы, праздничные дни, макс. выплата по травме), `isdayoff-fetch` (код 4), `calendar`/`fetchCalendar` (маппинг кода 4, наложение кода 8, праздники января в fallback, продление отпуска 2020).
