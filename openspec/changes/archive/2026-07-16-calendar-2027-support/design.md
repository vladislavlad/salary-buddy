## Context

Диапазон отображаемых годов задан константами `MIN_DISPLAY_YEAR` и `MAX_DISPLAY_YEAR` в `src/shared/lib/utils.ts`. Все потребители (CalendarProvider, App навигация, расчёт выплат) импортируют эти константы напрямую — нет отдельной конфигурации или динамической логики.

## Goals / Non-Goals

**Goals:**
- Разрешить загрузку и отображение календаря 2027 года.
- Обеспечить расчёт выплат на даты в 2027 году.

**Non-Goals:**
- Динамическое определение годов (например, `currentYear + 1`).
- Поддержка лет до 2024.
- Изменение логики загрузки календаря или API isdayoff.ru.

## Decisions

- **Одна константа**: Изменить только `MAX_DISPLAY_YEAR` с 2026 на 2027. Все потребители автоматически подхватят изменение — дополнительная работа не нужна.
- **API isdayoff.ru**: Предполагается, что API уже содержит данные за 2027 год (производственный календарь РФ публикуется заранее). Если данных нет — TanStack Query вернёт ошибку, которая обработается существующей логикой повторных попыток.

## Risks / Trade-offs

- [API isdayoff.ru не имеет данных за 2027] → Календарь года не загрузится, расчёты пропустят этот год (существующее поведение `if (!calendarData) continue`). Пользователь увидит пустой календарь.
- [Hardcoded константа требует обновления каждый год] → Принятое ограничение проекта. Переход на динамическую логику выходит за рамки этого изменения.
