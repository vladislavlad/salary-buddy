# Sick Leave (Больничные) — Delta

## MODIFIED Requirements

### Requirement: Fallback расчёт среднего заработка с коэффициентом

Система MUST применять районный коэффициент к окладу при fallback-расчёте среднего заработка для больничных. Формула: эффективный оклад × 24 / 730, где эффективный оклад = базовый оклад × (1 + коэффициент/100).

#### Scenario: Fallback с коэффициентом

- **GIVEN** оклад 100 000 ₽, коэффициент 30%
- **WHEN** расчёт fallback среднего заработка для больничного
- **THEN** используется оклад 130 000 ₽: 130 000 × 24 / 730 = 4 246.57 ₽/день

#### Scenario: Fallback без коэффициента

- **GIVEN** оклад 100 000 ₽, коэффициент не задан
- **WHEN** расчёт fallback среднего заработка для больничного
- **THEN** используется оклад 100 000 ₽: 100 000 × 24 / 730 = 3 287.67 ₽/день
