# Vacation (Отпускные) — Delta

## MODIFIED Requirements

### Requirement: Средний заработок с учётом коэффициента

Система MUST рассчитывать средний заработок для отпускных по фактическим gross выплатам за расчётный период (12 месяцев), включая выплаты, рассчитанные с районным коэффициентом. Коэффициент не применяется повторно к уже начисленным выплатам.

#### Scenario: Средний заработок включает коэффициент

- **GIVEN** за 12 месяцев gross с коэффициентом = 1 560 000 ₽, включённых дней = 351.6
- **WHEN** расчёт отпускных за 28 дней
- **THEN** средний дневной заработок = 1 560 000 / 351.6 = 4 436.86 ₽, отпускные = 4 436.86 × 28 = 124 232 ₽

#### Scenario: Коэффициент не применяется повторно

- **GIVEN** отпускные рассчитываются от gross, уже включающих коэффициент
- **WHEN** расчёт отпускных
- **THEN** коэффициент не накладывается повторно на средний заработок
